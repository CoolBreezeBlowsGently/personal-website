界面部分我更在意「顺手」——按钮在哪、点完发生什么、下一屏要不要重新找。 好看的界面很多，能让人第二次不用想的才难。

工作之外在学怎么做更好的 Web 体验，偶尔写点小工具自用。这个站就是其中之一： 手写 HTML / CSS / JavaScript，没有框架也没有构建步骤。
